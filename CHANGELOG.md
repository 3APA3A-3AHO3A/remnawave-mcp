# Changelog

## 1.1.0 — 2026-09-30
- **Приватность.** Новый параметр `REMNAWAVE_PRIVACY` (по умолчанию `strict`):
  - всегда скрываются учётные данные: приватные ключи Reality, SECRET_KEY, пароли, VLESS UUID, ссылки подключения, shortUuid и URL подписки клиента;
  - в `strict` личные данные клиентов (username, email, Telegram ID, IP, HWID, описание) заменяются псевдонимами вида `user~3fa2c1` — одинаковые значения дают одинаковый псевдоним, псевдоним можно передать обратно в команду.
- Команды, которые только отдают ключи подключения и «сырую» подписку, скрыты (открываются в `REMNAWAVE_PRIVACY=off`).
- Дополнительные команды включаются, только если их поддерживает установленная версия контракта.
- Контракты без пометок чтение/запись: GET считается чтением.
- Dependabot: еженедельная проверка новых версий `@remnawave/backend-contract`.

## 1.0.0 — 2026-09-30
- Первая версия под Remnawave 3.4.x (контракт `@remnawave/backend-contract` 3.4.4).
- Инструменты генерируются автоматически из контракта: 81 на чтение, 181 всего.
- Режим «только чтение» по умолчанию; логин, passkey, OTT, SECRET_KEY нод и API-токены недоступны всегда.
- Доп. инструменты: `find_user`, `geocheck_node`, `node_connections`, `user_connections`.
